IMPORTANT notes about the FASTA input file:

  • This service can only be used with Influenza nucleotide sequences.
  • Segment names in the FASTA headers are limited to PB2, PB1, PA, HA, NP, NA, MP, and NS.
  • The segment name must be surrounded by | characters and can be followed by a date in YYYY-MM-DD format. For example:
    >A/swine/Michigan/A02635726/2021|1B.2.1|1998B|TTTPPT|HA|2021-04-23
    where the segment is HA and the date is 2021-04-23.
  • TreeSort accepts 3 strain name formats within a FASTA header:
    • Everything remaining after the segment name is removed.
    • "EPI_ISL_" followed by a numeric value.
    • A, B, C, or D followed by 3–5 spans of text separated by / (e.g. A/swine/Iowa/A02635718/2021).
  • After selecting a FASTA input file, it is automatically validated; a summary or error message will be displayed.
